#Тестирование #Android

**Scrcpy** (от _Screen Copy_) — это бесплатная программа с открытым исходным кодом для отображения и управления Android-устройствами с компьютера.

## Основные возможности

- **Отображение экрана** Android-устройства на мониторе компьютера в реальном времени
- **Управление** с помощью мыши и клавиатуры (нажатия, свайпы, ввод текста)
- **Запись экрана** устройства
- **Передача файлов** между компьютером и устройством (drag & drop)
- **Без установки** каких-либо приложений на Android-устройство (работает через отладку по ADB)
- **Минимальные требования** — достаточно только включить отладку по USB на телефоне
- **Поддержка беспроводного подключения** (по Wi-Fi через ADB TCP/IP)

## Как запустить

1. **Включите отладку по USB** на Android: _Настройки → О телефоне → Номер сборки_ (нажать 7 раз) → _Настройки → Для разработчиков → Отладка по USB_
2. **Подключите** устройство к компьютеру USB-кабелем
3. **Скачайте** scrcpy с [официального GitHub](https://github.com/Genymobile/scrcpy)
4. **Запустите** исполняемый файл (scrcpy.exe на Windows)

## Полезные параметры запуска

- `scrcpy --max-size 1024` — ограничить разрешение
- `scrcpy --bit-rate 2M` — ограничить битрейт
- `scrcpy --record file.mp4` — запись экрана
- `scrcpy --no-audio` — отключить звук
- `scrcpy --turn-screen-off` — отключить экран устройства (экономия батареи)
- `scrcpy --stay-awake` — не давать экрану гаснуть
-  `scrcpy --tcpip` - беспроводное подключение
- `scrcpy --video-bit-rate=20M --max-fps=60` - качество
