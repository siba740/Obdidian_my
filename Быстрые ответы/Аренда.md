
### Кэш Chrome Windows

```
Чтобы очистить кэш и данные браузера Google Chrome в Windows 10, выполните следующие действия:

### Способ 1: Быстрый доступ через комбинацию клавиш (рекомендуется)

1. Откройте Google Chrome.
    
2. Нажмите комбинацию клавиш **Ctrl + Shift + Delete** на клавиатуре — сразу откроется нужное окно.
    
3. В появившемся окне выберите **Временной диапазон** (например, **Все время**, если хотите удалить абсолютно всё).
    
4. Установите галочки напротив пунктов, которые нужно очистить:
    
    - **История просмотров** (по желанию)
        
    - **Файлы cookie и другие данные сайтов** (учтите, что после этого придется заново входить на сайты)
        
    - **Кэшированные изображения и файлы** (основной источник накопления мусора)
        
5. Нажмите кнопку **Удалить данные**.
```

### Обновить Chrome WIndows

```
### Как обновить Google Chrome вручную

1. Откройте Google Chrome.
    
2. Нажмите на значок **трех точек** в правом верхнем углу окна.
    
3. В выпадающем меню наведите курсор на пункт **Справка**, а затем выберите **О браузере Google Chrome**.
    
4. Откроется специальная вкладка, где браузер **автоматически начнет проверку** наличия новых версий и их загрузку.
    
5. Если обновление найдено и скачано, появится кнопка **Перезапустить**. Нажмите ее, чтобы завершить установку (все открытые вкладки при этом сохранятся и откроются снова).
    

> **Полезный совет:** Если в этом окне отображается сообщение _«Браузер Google Chrome обновлен»_, значит, у вас установлена самая последняя актуальная версия, и никаких дополнительных действий предпринимать не нужно.
```
